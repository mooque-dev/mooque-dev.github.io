<p>The easy move was to ship the 82%. I argued to pause: the edit box dropped donors into an older fallback that nudged them toward the smallest contribution. The new question was how to make the easiest path a fair one that never felt coercive to donors.</p>
<p>The pushback on pausing was about the timeline. What got agreement was the bar: we held the fee box to a 90% benchmark set against other giving platforms. For scale, GoFundMe Pro says 75 to 85% of donors cover fees when the option is on by default.</p>
<blockquote>
<p>Introducing a modernized fallback control when a donor clicks "Edit" will increase the average fee opt-in value while maintaining or improving the existing conversion rate.</p>
</blockquote>
<p>I built interactive prototypes in Cursor and MagicPatterns where PMs and engineers could change thresholds, defaults and fallback logic and watch the outcome. It cut alignment time and surfaced constraints before high-fidelity design. You can still <a href="https://project-pleasant-dragonfly-294.magicpatterns.app">try the version 1 prototype</a> and <a href="https://project-inspiring-cove-378.magicpatterns.app">the future-state concept</a>.</p>

<p>I designed three variants grounded in defaults, anchoring and soft-decline (a slider, toggle buttons and a segmented dropdown) and tested them against the existing control in Pendo. Each was built production-ready, so the winner could ship platform-wide the day the test closed.</p>
